# STM32F401 Bare-Metal Driver Library

A bare-metal driver library for the STM32F401CCU6 developed from scratch without using STM32 HAL.

## Features

- GPIO Driver
- EXTI Driver
- NVIC Configuration
- SysTick Driver

## Planned Drivers

- TIM
- UART
- SPI
- I2C
- ADC
- DMA

## Toolchain

- STM32CubeIDE
- Embedded C

## MCU

STM32F401CCU6
